# FTC Team Araxys — Robotics Software

**FTC Team 29224 | 2025–2026**  
**Role: Team Captain & Head of Programming**

Welcome to the software repository for **FTC Team Araxys (29224)**. This repository documents the programming work behind our FIRST Tech Challenge (FTC) robot, including autonomous navigation, computer vision, localization, and robot control systems.

My involvement in FTC has grown from learning and developing robot code to leading the team's programming division and eventually serving as Team Captain.

## My Role & Contributions

As Team Captain and Head of Programming, I was responsible for both the technical development of our robot and helping coordinate the team's overall progress.

My primary contributions included:

- **Autonomous Programming:** Developing autonomous routines that allow the robot to navigate the competition field and complete tasks with minimal human intervention.
- **Computer Vision & Localization:** Integrating Limelight and AprilTag-based vision systems to improve robot localization and support accurate autonomous navigation.
- **Robot Control Systems:** Developing modular Java code for robot mechanisms, movement, and subsystem control.
- **Path Planning:** Working with the Pedro Pathing framework to implement and refine autonomous movement paths.
- **Code Architecture:** Organizing the programming system into reusable modules to improve maintainability, debugging, and collaboration.
- **Team Leadership:** Guiding programming development, coordinating technical decisions, and supporting other team members in learning robotics programming.

## Technical Stack

- **Java:** Primary programming language for robot software.
- **FTC SDK:** Robot control and hardware integration.
- **Limelight:** Computer vision and target detection.
- **AprilTag:** Vision-based localization.
- **Pedro Pathing:** Autonomous navigation and path following.

## Repository Structure

The repository contains the software developed for our FTC robot, including autonomous routines, subsystem implementations, and supporting utilities.

The code is organized to separate different robot functions and make the system easier to understand, test, and maintain.

## About FIRST Tech Challenge

FIRST Tech Challenge is an international robotics competition in which student teams design, build, and program robots to complete game-specific challenges. Teams compete through a combination of autonomous robot operation, driver-controlled performance, engineering design, and collaboration.

For me, FTC has been an opportunity to apply programming and mathematics to real engineering systems while developing technical leadership, problem-solving, and teamwork skills.
